How to run this project
Step 1 Run Backend API

-go to \API\User.API
-open User.API.slnx in Visual Studio (not VsCode)
-run http

Step 2 Run Frontend UI

-go to \UI\User-Management
-open that folder in VSCode
-run 'ng serve' in terminal
-click the link that shown in terminal(localhost:xxxx) to see the website
